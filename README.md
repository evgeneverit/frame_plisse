# FRAME — системы плиссе

Сайт-визитка компании **FRAME** (г. Самара).

Производство и продажа:
- Раздвижные перегородки плиссе
- Шторы плиссе
- Москитные сетки плиссе

## Структура проекта

```
frame_plisse/
├── index.html          # Основная страница
├── css/
│   └── styles.css      # Все стили
├── js/
│   └── main.js         # Скрипты (форма + мобильное меню)
└── README.md
```

## Как запустить локально

Просто откройте `index.html` в браузере или используйте любой статический сервер:

```bash
# например, с Python
python -m http.server 8000
```

Затем откройте http://localhost:8000

## Разработка

```bash
git clone https://github.com/evgeneverit/frame_plisse.git
cd frame_plisse
```

Откройте папку в VS Code и работайте как обычно.
