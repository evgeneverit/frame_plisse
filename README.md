# FRAME — системы плиссе

Сайт-визитка компании **FRAME** (г. Самара).

Производство и продажа:
- Раздвижные перегородки плиссе
- Шторы плиссе
- Москитные сетки плиссе

## Структура

- `index.html` — одностраничный лендинг (всё в одном файле: HTML + CSS + JS)

## Как запустить локально

Просто откройте `index.html` в браузере или используйте любой статический сервер:

```bash
# например, с Python
python -m http.server 8000
```

## Разработка

Репозиторий готов к клонированию:

```bash
git clone https://github.com/evgeneverit/frame_plisse.git
cd frame_plisse
```

Далее можно открывать проект в VS Code и коммитить изменения.
